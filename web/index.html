          How it works

          • Private. Everything happens on your computer, in this browser tab. Your images are never uploaded.
          • Ordered. Images are sorted by file name in natural order (2.jpg comes before 10.jpg), so number your files to control the order.
          • Organised. Every image gets the same height, then the rows are balanced into a neat rectangle: the same layout as the original Python script.
          • Compatible. New boards are saved in the PureRef 1.10 format, which PureRef 1.10, 1.11 and 2 all open. Boards from any of them can be saved as one image or split back into images. Any image your browser can display works: JPG, PNG, WebP, GIF, BMP, AVIF.
          Based on PureRef-format by Fyor. Not affiliated with PureRef.
